# 💵 Calculadora de Propinas

Calculadora para dividir la cuenta y la propina entre varias personas —
porcentajes rápidos (10/15/20/25%), porcentaje personalizado y división en
tiempo real. HTML/CSS/JS puro, sin dependencias.

Gratis para usar, modificar y regalar. Útil como está, o como base para tu
propia calculadora (cambiar moneda, agregar impuestos, etc.).

## Usar

Abrí `index.html` en el navegador, o serví la carpeta con cualquier servidor
estático (GitHub Pages, Netlify, `npx serve`).
